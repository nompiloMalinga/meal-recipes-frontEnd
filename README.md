# Meal Recipes Frontend

An Angular web application that allows users to browse and search for meals.

## Features
- Displays a list of meal categories fetched from the backend
- Search for meals by name using a search box
- Clean and responsive user interface

## Tech Stack
- Angular
- TypeScript
- HTML & CSS

## Setup
1. Clone the repository
2. Run `npm install`
3. Run `ng serve`
4. Navigate to `http://localhost:4200`
